## 📋 Sobre el proyecto

**webcomepormenos** genera planes de comida diarios y semanales ajustados a un **presupuesto máximo**, usando datos de precios en tiempo real de productos de consumo. El usuario configura sus preferencias dietéticas (vegano, keto, sin gluten, etc.) y la app optimiza automáticamente la lista de la compra para minimizar el gasto total.

La propuesta combina lo mejor de varias apps de referencia:

| App de referencia | Lo que aporta |
|---|---|
| Yummly | Recetas personalizadas |
| Mealime | Planificación de comidas |
| Too Good To Go | Enfoque en el ahorro |
| MyFitnessPal | Control nutricional |

**Diferenciador:** optimización económica inteligente — el motor no solo sugiere recetas que gustan, sino las que mejor se ajustan al presupuesto disponible esa semana.

> *webcomepormenos generates daily/weekly meal plans that fit a maximum budget using real-time consumer product pricing. It blends personalized recipes, meal planning, a savings-first mindset, and nutritional tracking — with smart economic optimization as its core differentiator.*

---

## ✨ Funcionalidades

- 📅 Generación de planes de comida diarios y semanales
- 💶 Ajuste automático a un presupuesto máximo definido por el usuario
- 🥦 Preferencias dietéticas: vegano, keto, sin gluten, y más
- 🛒 Optimización de la lista de la compra para minimizar el gasto
- 📡 Precios de productos de consumo combinando Open Prices y la API de Mercadona

---

## 🛠️ Stack tecnológico

- [Next.js 16](https://nextjs.org/)
- [React 19](https://react.dev/)
- TypeScript
- Tailwind CSS 4
- [Open Prices](https://prices.openfoodfacts.org/api/docs) (Open Food Facts) — base de precios abierta y documentada
- API no oficial de Mercadona (`tienda.mercadona.es/api/`) — precios reales de supermercado español

> ⚠️ La integración con Mercadona usa una API no documentada oficialmente (ingeniería inversa de la tienda online). Funciona bien para fines de demo/portfolio, pero puede cambiar sin aviso y no cuenta con soporte oficial.

## 🚀 Empezar

```bash
git clone https://github.com/MMMazaira/webcomepormenos.git
cd webcomepormenos
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en el navegador.
